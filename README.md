## If installing msdlive-cli for the first time, please run the following command:
#### `pip install --extra-index-url https://msd-live.github.io/msdlive-cli-distro/simple/ msdlive-cli`

## If upgrading to new version of msdlive-cli, please run the following command:
#### `pip install --upgrade --extra-index-url https://msd-live.github.io/msdlive-cli-distro/simple/ msdlive-cli`
